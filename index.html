How to read this project

Bounded, source-located, disagreement-preserving

01

Separate the layers

Observations, calibrations, reductions, statistics, models, and interpretations become different nodes.

02

Stop explicitly

Missing raw data, inaccessible sources, and depth limits appear as frontiers—not as invisible confidence.

03

Review edges, not votes

Each accepted dependency was reverse-reviewed. Agreement between models never substitutes for evidence.

04

Keep conclusions narrow

A model-specific exclusion does not become a family-wide result; an operational criterion does not become an ontology.

Current status

This is an AI-assisted methods prototype based on a bounded historical audit. It is not expert consensus, peer review, or a credibility score.
